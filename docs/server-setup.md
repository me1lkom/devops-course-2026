# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- **Название виртуальной машины:** devops-vm
- **Средство виртуализации:** Oracle VirtualBox 7.1.8
- **Операционная система:** Ubuntu Server 24.04.5 LTS (ARM64)
- **Оперативная память:** 2048 МБ
- **Количество ядер процессора:** 2
- **Объём виртуального диска:** 25 ГБ
- **Тип диска:** VDI, динамически расширяемый

## 2. Сетевые интерфейсы
### Адаптер 1 — NAT
- **Интерфейс:** enp0s8
- **IP-адрес:** 10.0.2.15/24
- **Тип подключения:** NAT

### Адаптер 2 — Host-only
- **Интерфейс:** enp0s9
- **IP-адрес:** 192.168.56.2/24
- **Тип подключения:** Host-only

## 3. Правило проброса портов
- **Название правила:** ssh
- **Протокол:** TCP
- **Адрес хостовой системы:** 127.0.0.1
- **Порт хостовой системы:** 2222
- **Адрес гостевой системы:** не указан
- **Порт гостевой системы:** 2222

## 4. Учётные записи
### Пользователь student
- **Имя пользователя:** student
- **Назначение:** первоначальная настройка сервера.
- **Привилегии:** возможность выполнения административных команд через sudo.
- **Аутентификация:** по паролю в локальной консоли Ubuntu.
- **SSH-доступ:** запрещён текущей конфигурацией SSH.

### Пользователь devops
- **Имя пользователя:** devops
- **Назначение:** удалённое администрирование сервера.
- **Группы:** devops, sudo, users.
- **Привилегии:** выполнение административных команд через sudo.
- **SSH-аутентификация:** по ключу ED25519.
- **Открытый ключ на сервере:** /home/devops/.ssh/authorized_keys
- **Закрытый ключ на macOS:** ~/.ssh/devops_vm

## 5. Служба SSH
- **Служба:** ssh.service
- **Порт:** 2222/TCP
- **Основной конфигурационный файл:** /etc/ssh/sshd_config
- **Файл дополнительных настроек:** /etc/ssh/sshd_config.d/99-hardening.conf
- **Резервная копия:** /etc/ssh/sshd_config.backup

### Директивы
| Директива | Значение | Назначение |
|---|---|---|
| Port | 2222 | Нестандартный порт SSH |
| PermitRootLogin | no | Запрет входа под root |
| PasswordAuthentication | no | Отключение парольной аутентификации |
| PubkeyAuthentication | yes | Разрешение входа по SSH-ключу |
| PermitEmptyPasswords | no | Запрет пустых паролей |
| MaxAuthTries | 3 | Максимальное число попыток аутентификации |
| LoginGraceTime | 30 | Время на прохождение аутентификации |
| AllowUsers | devops | Разрешение SSH-доступа только пользователю devops |
| X11Forwarding | no | Отключение перенаправления графических приложений |
| ClientAliveInterval | 300 | Интервал проверки активности клиента |
| ClientAliveCountMax | 2 | Максимальное число проверок без ответа |

## 6. Правила межсетевого экрана
- **Состояние:** active
- **Политика входящих соединений:** deny
- **Политика исходящих соединений:** allow
- **Уровень журналирования:** medium

## 7. Снимки состояния
### 01-clean-install
Создан после установки Ubuntu Server 24.04.5 LTS, обновления системы и настройки сетевых адаптеров.

### 02-keys-configured
Создан после настройки учётной записи devops и аутентификации по SSH-ключу.

### 03-ssh-hardened
Создан после усиления защиты SSH-сервера: изменения порта, отключения парольной аутентификации и ограничения доступа.

## 8. Веб-сервер
- **Веб-сервер:** Nginx
- **Конфигурация:** /etc/nginx/sites-available/devops-site
- **Каталог ресурса:** /var/www/devops-site
- **Владелец:** devops:devops
- **Права каталогов:** 755
- **Права файлов:** 644
- **TLS-сертификат:** /etc/ssl/certs/devops.crt (644)
- **Закрытый ключ:** /etc/ssl/private/devops.key (600, root)
- **Команда формирования сертификата:**
  sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/devops.key -out /etc/ssl/certs/devops.crt -subj "/CN=devops.local" -addext "subjectAltName=DNS:devops.local"
- **Срок действия сертификата:** 365 дней.


## 9. Контейнеризация
- **Операционная система:** Ubuntu Server 24.04 LTS (ARM64).
- **Docker Engine:** версия 29.9.2, установлен из официального репозитория Docker (`download.docker.com/linux/ubuntu`).
- **Docker Compose:** версия v5.6.1.
- **Группа docker:** пользователь `devops`. Членство в группе предоставляет привилегии, сопоставимые с root.

### Расположение проекта
- **Каталог приложения на сервере:** `/home/devops/app`.
- **Файл Compose:** `/home/devops/app/docker-compose.yml`.
- **Dockerfile:** `/home/devops/app/Dockerfile`.
- Исходные файлы передаются с Mac на Ubuntu через `rsync` с исключением `.env`.

### Переменные окружения
- **Файл:** `/home/devops/app/.env`.
- **Владелец:** `devops`.
- **Права:** `600` (`rw-------`).
- Содержит параметры PostgreSQL и пароль.
- Настоящий `.env` не хранится в Git и не включается в Docker-образ. В репозитории находится только `.env.example`.

### Контейнеры и сеть
- **app:** Flask-приложение, запускаемое через Gunicorn от непривилегированного пользователя `app`.
- **db:** PostgreSQL 16 Alpine.
- **Сеть:** `app_backend` (bridge).
- Приложение обращается к PostgreSQL по имени сервиса `db` через внутренний DNS Docker.

### Публикация портов
- **Приложение:** `127.0.0.1:5000:5000`. Порт доступен только локально на Ubuntu.
- **PostgreSQL:** порт `5432` не публикуется на хосте. Доступен приложению внутри сети Docker.
- Внешние HTTPS-запросы принимает Nginx на порту `443`.

### Хранение данных
- **Именованный том:** `app_db_data`.
- **Точка монтирования:** `/var/lib/postgresql/data` внутри контейнера PostgreSQL.
- `docker compose down` удаляет контейнеры и сеть, сохраняя том.
- `docker compose down -v` удаляет также том и данные PostgreSQL.

### Обратный прокси-сервер
- **Nginx:** `/etc/nginx/sites-available/devops-site`.
- **Внешний адрес приложения:** `https://devops.local/app/`.
- **Проксирование:** `location /app/` с `proxy_pass http://127.0.0.1:5000/;`.
- Передаются заголовки `Host`, `X-Real-IP`, `X-Forwarded-For` и `X-Forwarded-Proto`.
- Статический сайт из практической работы № 6 продолжает обслуживаться по адресу `https://devops.local/`.
