## Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
- При ветвление в Git не создаётся дубль проекта, ветка может состоять из одного коммита.
- В SVN при ветвлении создаётся копия всего проекта.

## Можно ли в SVN сделать коммит без интернета? Почему?
- Вся информация о коммитах храниться на сервере, поэтому чтобы сделать коммит необходим интернет.

## В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- Старый проект построенный вокруг SVN
- Когда необходимо строго контролировать доступ к папкам проекта
- В проектах, где не используется ветвление
